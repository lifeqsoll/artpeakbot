# 🎨 ArtPeak Bot
**ArtPeak Bot** — современный Telegram-бот для художников и арт‑сообщества: загрузка артов, просмотр ленты, реакции (лайк/дизлайк), комментарии, поиск по хэштегам, профили с настройками приватности, подписки и топы.

- **Бот в Telegram**: `https://t.me/ArtPeakArtbot` (может работать не 24/7)
- **Контакты создателей**: `@emosensei`, `@SuperApelsins`, `@uselsness`

---

## ✨ Основные возможности

- **Загрузка артов**: отправка изображения с подписью (можно добавлять хэштеги `#tag`).
- **Автопроверка контента**: фильтрация недопустимого контента при загрузке (CLIP + NSFW‑модель).
- **Лента артов**: просмотр работ сообщества, реакции (❤️/👎), обновление статистики.
- **Комментарии**: возможность оставить комментарий к арту.
- **Профили**: ник, “о себе”, аватар; **приватный профиль** (скрытие данных).
- **Подписки**: подписка/отписка на авторов, просмотр подписчиков.
- **Топы “за всё время”**:
  - **топ артов** (по лайкам)
  - **топ авторов** (по подписчикам)
- **Поиск**:
  - по хэштегам
  - по профилям (ник/юзернейм)
- **Модерация и жалобы**:
  - жалоба на арт и на профиль
  - ручная модерация “сомнительных” изображений (отправка в поддержку)
  - блокировка/разблокировка профилей и **апелляции**
  - просмотр и восстановление удалённых артов (для модераторов)

## 🚀 Быстрый старт (локально)

### 1) Установка зависимостей

В репозитории сейчас нет `requirements.txt`, поэтому зависимости ставятся вручную. Пример:

```bash
python -m venv .venv

# Windows PowerShell:
.\.venv\Scripts\Activate.ps1

pip install -U pip
pip install python-telegram-bot pillow transformers torch

# Для CLIP (варианты отличаются по окружению):
# - openai/CLIP: pip install git+https://github.com/openai/CLIP.git
# - либо пакет `clip` (если используется именно он в вашем окружении)
```

> Если используете CUDA — убедитесь, что `torch` установлен с поддержкой GPU под вашу версию CUDA.

### 2) Настройка токена и модерации

В коде бота используется:

- **`BOT_TOKEN`** — токен Telegram‑бота
- **`SUPPORT_USERNAME`** — ник поддержки (показывается пользователям)
- **`SUPPORT_USER_IDS`** — список Telegram ID модераторов (доступ к мод‑командам и мод‑кнопкам)

Важно: **не храните токен в репозитории**. Если токен уже попадал в код/публичный доступ — **сразу перевыпустите его через @BotFather**.

### 3) Запуск

Из папки `C:\projects`:

```bash
python -m artpeakbot.main
```

Альтернатива (если запускаете напрямую файл):

```bash
python .\artpeakbot\main.py
```

## 📁 Структура проекта

```text
artpeakbot/
├── __init__.py
├── main.py
├── bot_logic.py
├── bot_handlers.py
├── split_from_original.py
├── README.md
└── database.db              # создается автоматически при первом запуске
```

### Назначение файлов

- **`main.py`**: точка входа — создаёт `Application`, регистрирует хендлеры, запускает polling и планировщик фоновых задач.
- **`bot_handlers.py`**: слой взаимодействия с пользователем — команды/кнопки/сообщения, меню и состояния через `context.user_data`.
- **`bot_logic.py`**: бизнес‑логика и инфраструктура — SQLite (`database.db`), профили/подписки/топы/поиск, жалобы/модерация/апелляции, проверка изображений (CLIP + NSFW classifier).
- **`split_from_original.py`**: утилита для разбиения исходного монолитного файла на `bot_logic.py` и `bot_handlers.py` (для работы бота не обязательна).
- **`database.db`**: локальная SQLite база (создаётся автоматически при `init_db()`).

## ⚙️ Как работает бот (архитектура)

### 1) Запуск

1. Запускается `main.py`.
2. Импортируются обработчики из `bot_handlers.py` и функции из `bot_logic.py`.
3. Вызывается `init_db()` для создания/проверки таблиц SQLite.
4. Регистрируются хендлеры и стартует polling.

### 2) Обработка событий Telegram

- **Команды** (`/start`, `/deleted_arts`, `/appeals`) → `CommandHandler`
- **Inline‑кнопки** → `CallbackQueryHandler`
- **Фото/текст** → `MessageHandler`

`bot_handlers.py` принимает событие и вызывает нужную логику из `bot_logic.py`.

### 3) Загрузка и проверка арта

1. Пользователь отправляет фото (с подписью или без, хэштеги — в подписи `#tag`).
2. Бот скачивает изображение и проверяет его:
   - базовая проверка (валидность/размер и т.п.)
   - NSFW‑проверка (CLIP + `Falconsai/nsfw_image_detection`, если доступна)
3. Если изображение проходит — арт сохраняется в БД и становится доступен для просмотра/оценок.
4. Если проверка не пройдена — загрузка уходит в ручную модерацию (отправка в поддержку).

### 4) Социальные функции

- реакции (❤️/👎) и обновление статистики
- комментарии
- подписки на авторов и список подписчиков
- поиск по профилям/хэштегам
- топ артов (по лайкам) и топ авторов (по подписчикам) “за всё время”

### 5) Модерация

- жалобы на арты и профили
- доступ модераторов по `SUPPORT_USER_IDS`
- блокировка/разблокировка, апелляции
- просмотр/восстановление удалённых артов (команда `/deleted_arts`)
